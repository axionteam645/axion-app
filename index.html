STAKING SECURITY MODEL

Clean Reward Logic

The recommended staking model uses a prefunded reward pool instead of minting new tokens. This keeps the total supply stable and easier to explain.

Fixed Supply

No staking mint function is required. Rewards come from the funded pool.

Locked Pools

All pools have fixed unlock dates. No flexible stake is used.

No Hidden Fees

The UI presents staking amount, APY, lock period, and estimated reward clearly.

On-Chain Claims

Claim and unstake actions should be verified on-chain through the staking contract.

Reward Pool

The contract should hold enough AXION to cover future reward obligations.
